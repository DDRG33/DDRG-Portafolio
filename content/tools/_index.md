# 🛠️ Directorio de Herramientas Especializadas

Repositorio personal y clasificado de soluciones de software utilizadas en investigaciones forenses y recopilación de inteligencia.

---

### 🔍 Inteligencia de Fuentes Abiertas (OSINT)

*   **Sherlock**
    *   *Uso:* Búsqueda y rastreo de perfiles de usuario en múltiples redes sociales de forma automatizada.
*   **Spiderfoot**
    *   *Uso:* Automatización de OSINT para el reconocimiento de objetivos, dominios y direcciones IP.
*   **Maltego**
    *   *Uso:* Análisis de enlaces y minería de datos para la representación gráfica de relaciones en investigaciones.

---

### 💾 Análisis Forense y Respuesta ante Incidentes (DFIR)

*   **Autopsy**
    *   *Uso:* Plataforma de interfaz gráfica para el análisis forense digital de discos duros y tarjetas de memoria.
*   **Volatility**
    *   *Uso:* Framework avanzado para la extracción y análisis de artefactos directamente desde la memoria RAM.
*   **Wireshark**
    *   *Uso:* Analizador de protocolos de red para la captura e inspección profunda del tráfico malicioso.
